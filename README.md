# Personal Portfolio

Personal portfolio of Arul Selvan Mahalingam — Full-Stack Developer & AI/ML Engineer.

## Live Demo
Check out the live deployment at [https://arulselvanmahalingam.vercel.app](https://arulselvan.dev/).

## Built With
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion
- **Hosting**: Vercel

## Features
- **Hero**: Minimal-technical layout with typewriter intro, orbiting elements, and premium dark backing spotlights.
- **About**: Profile introduction featuring a client-side live GitHub stats ticker (repos, stars, relative last-commit timer) and scroll-triggered counting stats.
- **Education**: Timeline highlight showing academic achievements and coursework.
- **Experience**: Clean details tracing professional milestones, internships, and research roles.
- **Achievements**: Visual layout showcasing national hackathons and government-funded MSME projects.
- **Featured Projects**: Interactive spotlights tracing system features, tech stack pills, and repository links.
- **Skills & Certifications**: Categorized technical grids with AWS and other badge showcases.
- **Contact**: Fast communication form containing a client-side live local time indicator in IST.

## Getting Started

### Prerequisites
Ensure you have [Node.js](https://nodejs.org) installed on your system.

### Setup Instructions
1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

4. Environment Variables:
   If any client tokens or analytics keys are added in the future, create a `.env.local` file at the root of the project. A template has been provided in `.env.example`.
